# Локальный генеалогический проект

Проект хранит одно каноническое семейное дерево в `family-tree.ged`. В дерево попадают только подтверждённые факты; гипотезы, противоречия и история поиска ведутся отдельно.

## Структура

- `family-tree.ged` — канонический GEDCOM 5.5.1 в UTF-8.
- `AGENTS.md` — обязательные правила исследования и приватности.
- `research/research-log.md` — хронологический журнал поиска.
- `research/strategy.md` — текущие цели, ограничения и следующие шаги.
- `research/conflicts.md` — неразрешённые и разрешённые противоречия.
- `research/evidence/` — документы, расшифровки и архивные пакеты страниц.
- `research/reports/` — доказательные отчёты.
- `research/requests/` — проекты архивной переписки.
- `references/` — старые экспорты и материалы для сверки, не рабочее дерево.

## Рабочий цикл

1. Сформулировать один проверяемый вопрос.
2. Проверить ограничения по персоне и приватность.
3. Найти и сохранить источник вместе с происхождением.
4. Идентифицировать человека и присвоить утверждениям статусы.
5. Внести в GEDCOM только `CONFIRMED`.
6. Обновить журнал и проверить дерево.

Git в шаблоне не инициализирован. Не публикуйте проект без отдельного решения о данных потенциально живых людей.
