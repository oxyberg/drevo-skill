# Структура проекта

## Создание

Создать новый проект командой:

```sh
python3 <путь-к-скиллу>/scripts/init_project.py <новый-каталог>
```

Скрипт копирует обезличенный шаблон и не инициализирует Git. Если каталог уже содержит файлы, остановиться и разобрать их вручную.

## Назначение файлов

```text
family-tree.ged                 единственное каноническое дерево
AGENTS.md                       обязательные правила проекта
README.md                       краткое описание структуры и рабочего цикла
references/                     старые экспорты и справочные копии
research/research-log.md        хронологический журнал поиска
research/conflicts.md           открытые и разрешённые противоречия
research/strategy.md            текущие цели, ограничения и следующие шаги
research/evidence/documents/    неизменённые документы
research/evidence/transcriptions/ расшифровки
research/evidence/webpages/     архивные пакеты веб-страниц
research/reports/               доказательные выводы
research/requests/              проекты архивной переписки
```

Не хранить доказательный вывод только в интерфейсном индексе или заметке агента.

## Импорт существующего дерева

1. Не редактировать исходный экспорт.
2. Сохранить его в `references/` с понятным именем и происхождением.
3. Выбрать или создать один `family-tree.ged` как канонический.
4. Сравнить количество персон, семей, событий, источников и семейные связи.
5. Считать сведения без источников исходными утверждениями, а не подтверждёнными фактами.
6. Не объединять дубликаты автоматически по имени.

## Необязательный просмотрщик

Если пользователь просит локальный просмотрщик:

- читать только корневой `family-tree.ged`;
- не добавлять редактирование и отдельную генеалогическую базу;
- хранить интерфейсный индекс только для статусов, пробелов и ссылок на `research/`;
- слушать только `127.0.0.1`;
- скрывать сведения потенциально живых людей по умолчанию;
- не подключать внешнюю аналитику и не передавать GEDCOM наружу.
