# Воспроизводимая обработка изображений

Использовать эти инструменты только для производных слоёв. Исходный файл или доказательный кадр хранить неизменным. Все команды работают локально, не отправляют изображения во внешние сервисы, не используют генеративное восстановление и не записывают абсолютные пути в манифесты.

## Зависимости и общие свойства

- `create_image_derivatives.py`, `split_image_bands.py` и `make_contact_sheet.py` требуют Python 3 и Pillow;
- `ocr_images.py` требует локальный исполняемый файл Tesseract и установленную модель выбранного языка;
- входом может быть список файлов или каталог; каталоги просматриваются без рекурсивного обхода;
- графические команды обрабатывают однокадровые изображения и явно отклоняют многостраничный TIFF или GIF, чтобы не потерять страницы молча; сначала извлечь все страницы разрешённым локальным инструментом;
- каждый вход получает порядковый номер и префикс SHA-256, поэтому даже одинаковые копии из разных каталогов не перезаписывают друг друга;
- существующие результаты не перезаписываются без `--overwrite`;
- каждый набор получает JSON-манифест с параметрами и контрольными суммами.

Для каждого запуска выбирать отдельный каталог результатов. Если производная команда завершилась с ошибкой после создания части файлов, не считать набор законченным. Проверить причину, удалить или изолировать неполный набор либо осознанно повторить команду с `--overwrite`, затем проверить манифест и SHA-256. `--overwrite` заменяет только запланированные файлы и не удаляет устаревшие или посторонние результаты.

Имя исходного файла само может содержать ФИО или архивный шифр. Перед передачей производного пакета использовать `--redact-source-names` во всех командах цепочки: тогда basename не попадёт в имена результатов, подписи и манифесты. Связь сохраняется по порядковому номеру и SHA-256. Без этого флага пакет остаётся приватным, даже если в нём нет абсолютных путей; для контактного листа также доступен `--no-labels`.

JSON-манифест описывает преобразование, но не заменяет итоговый перечень контрольных сумм доказательного пакета. После завершения набора запустить `scripts/write_checksums.py <каталог-пакета>`, затем `scripts/verify_checksums.py <каталог-пакета>`.

## Создать варианты для чтения

```sh
python3 <путь-к-скиллу>/scripts/create_image_derivatives.py evidence/pages \
  --output-dir research/derivatives \
  --mode gray --mode normalize --mode red \
  --binary-threshold 160
```

По умолчанию создаются усиленная градация серого и нормализация фона. Можно повторять `--mode` для каналов `red`, `green`, `blue` и `--binary-threshold` для нескольких порогов. Результаты сохраняются как lossless PNG. Выбирать полезный вариант визуально по читаемости, а спорные буквы всегда сверять с исходником.

Не использовать цветовой канал как универсальный способ «выделить чернила»: цвет бумаги, водяного знака, освещения и записи различается. Сохранять параметры выбранной обработки и не выдавать её за восстановленный оригинал.

## Разделить длинный лист на полосы

```sh
python3 <путь-к-скиллу>/scripts/split_image_bands.py research/derivatives \
  --output-dir research/bands --size 800 --overlap 200
```

По умолчанию создаются горизонтальные полосы; для колонок использовать `--axis vertical`. Перекрытие сохраняет контекст на границе. `bands-manifest.json` содержит точные координаты каждой полосы относительно изображения после применения EXIF-ориентации. Предохранители `--max-bands` и `--max-output-pixels` останавливают ошибочную конфигурацию с почти полным перекрытием до записи файлов; повышать их только после оценки диска и ожидаемого количества полос.

## Сделать контактный лист

```sh
python3 <путь-к-скиллу>/scripts/make_contact_sheet.py research/bands \
  --output research/contact-sheet.png --columns 4
```

Контактный лист предназначен для навигации по большому набору, а не для чтения мелких деталей. Порядок следует порядку входных аргументов и стабильной сортировке имён внутри каждого каталога; манифест связывает ячейки с исходными SHA-256. Для очень больших наборов делить материал на осмысленные диапазоны, не повышая `--max-images` и `--max-pixels` без оценки памяти.

## Создать локальный OCR-индекс

```sh
python3 <путь-к-скиллу>/scripts/ocr_images.py research/derivatives \
  --output-dir research/ocr --language rus --psm 6
```

Для каждого изображения создаются обычный текст и TSV с координатами распознанных блоков. Языки можно объединять, например `--language rus+eng`. Проектный словарь допустимо передать через `--user-words`, но не включать персональный словарь в публичный скилл и не переносить его содержимое в манифест: там сохраняются только имя файла и SHA-256.

OCR является навигационным индексом. Проверять каждое совпадение по изображению, не переносить машинный текст напрямую в GEDCOM и не трактовать отсутствие совпадения как отсутствие записи.

## Масштабировать без привязки к сайту

Разделять два уровня:

1. Минимальный адаптер конкретного сайта получает разрешённые файлы или кадры и фиксирует URL, позицию, координаты и масштаб.
2. Универсальные команды этого скилла обрабатывают уже сохранённые локальные файлы и создают одинаковые манифесты независимо от архива.

Не добавлять в универсальные скрипты cookies, токены, архивные шифры, фамильные словари, селекторы интерфейса или предположения о нумерации листов. Сайт-специфичный адаптер хранить отдельно и заменять при изменении интерфейса, не меняя доказательную модель.
