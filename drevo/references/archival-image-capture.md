# Пакетная фиксация архивных изображений

Использовать этот порядок для архивных просмотрщиков, особенно при авторизованном, платном или ограниченном по времени доступе. Соблюдать условия доступа, не обходить технические ограничения и не сохранять cookies, токены, заголовки авторизации или данные сессии.

## Содержание

- подготовка сеанса;
- сохранение доказательного слоя;
- разделение нумераций;
- структура и метаданные пакета;
- проверка полноты;
- завершение сеанса.

## Сначала подготовить сеанс

1. Сформулировать, какое дело или непрерывный диапазон нужен и зачем.
2. Записать архив, шифр, заголовок, URL карточки и просмотрщика, идентификатор документа, заявленное число страниц и дату доступа.
3. При доступном предпросмотре проверить начало, середину и конец документа; установить фактическое число позиций просмотрщика. Если изображения открываются только после оплаты, перенести эту калибровку в первые минуты уже разрешённого пользователем сеанса.
4. Оценить количество кадров, время и место на диске. Оставить запас не менее двукратного оценочного объёма до сборки производных файлов.
5. На двух доступных позициях проверить фактический масштаб, размер окна, pixel ratio, натуральный размер полотна, крайние координаты и читаемость почерка.
6. Подготовить каталог, манифест, контроль состояния и правило именования до запуска оплачиваемого времени.
7. Если требуется покупка, собрать и проверить заказ, затем остановиться перед необратимым подтверждением или оплатой без прямого указания пользователя.

## Сохранять доказательный слой

- Предпочитать исходный файл архива, если он официально доступен для скачивания. Сохранять полученные байты без преобразования.
- Если доступен только просмотрщик, называть результат кадром или снимком просмотрщика, а не архивным оригиналом.
- При полотне больше окна сохранять перекрывающиеся кадры. Для пакета фиксировать единые масштаб, pixel ratio и размер окна; для каждого кадра — позицию просмотрщика, координаты `x/y`, ширину и высоту. При изменении настроек начинать новый пакет.
- Сохранять непрерывную последовательность позиций, когда задача требует поиска по содержанию. Разреженную выборку помечать как навигационную.
- Не принимать кадр с индикатором загрузки, пустым полотном, предыдущей страницей или неожиданным совпадением с соседней позицией.
- Не удалять водяные знаки, поля или интерфейс из доказательных кадров. Допустимые обрезки и улучшения выполнять только в производной копии.
- После каждых нескольких позиций атомарно обновлять состояние через `scripts/update_capture_state.py`, чтобы продолжить работу без пропусков и дублирования. Одновременно состояние должен менять только один процесс.

## Разделять нумерации

Хранить раздельно:

- позицию или номер файла в просмотрщике;
- видимый архивный лист и `об.`;
- номер страницы PDF или другого контейнера;
- имя локального файла.

Связывать их таблицей. Не вычислять архивный лист только по смещению позиции, пока соответствие не подтверждено минимум двумя видимыми контрольными точками и не проверена непрерывность диапазона.

## Структура пакета

Создавать пакет через `scripts/init_capture_package.py`:

```text
YYYY-MM-DD_описание-источника/
├── README.md
├── capture-state.json
├── page-sizes.json
├── исходные-кадры/
├── собранные-изображения/
├── производные/
├── контроль/
└── sha256.txt
```

В `page-sizes.json` хранить одну запись на позицию: размер полотна, архивный лист при уверенном чтении и список кадров с координатами и путями. Не включать предположительный номер листа как подтверждённый.

В `capture-state.json` раздельно хранить URL карточки и просмотрщика, масштаб, pixel ratio и размер окна фиксации. До начала доступа проверить структуру командой:

```sh
python3 <путь-к-скиллу>/scripts/audit_capture_package.py --preflight <пакет>
```

Предсеансовый режим допускает отсутствующие изображения и неоткалиброванный масштаб, но сообщает о них предупреждениями. Полный аудит после фиксации считает их ошибками.

Не предполагать четыре кадра или другую схему до калибровки сайта. После проверки просмотрщика записать настройки и ожидаемые части, например:

```sh
python3 <путь-к-скиллу>/scripts/update_capture_state.py <пакет> \
  --zoom 100% --pixel-ratio 2 --viewport-width 4096 --viewport-height 4096 \
  --tile-label верх-слева --tile-label верх-справа \
  --tile-label низ-слева --tile-label низ-справа
```

После сохранения и проверки позиции отметить её отдельно: `scripts/update_capture_state.py <пакет> --complete N`. Для неисправимого пропуска использовать `--exception N:причина`, а для повторной фиксации — `--reopen N`.

Пример одной записи; элемент `tiles` повторить для каждой ожидаемой части:

```json
{
  "position": 1,
  "viewer_file": "file-0001",
  "archive_folio": null,
  "canvas": {"width": 6000, "height": 4500},
  "tiles": [
    {
      "label": "верх-слева",
      "path": "исходные-кадры/позиция-0001_верх-слева.png",
      "x": 0,
      "y": 0,
      "width": 4096,
      "height": 4096
    }
  ]
}
```

## Проверять полноту

После фиксации запустить:

```sh
python3 <путь-к-скиллу>/scripts/audit_capture_package.py <пакет>
python3 <путь-к-скиллу>/scripts/assemble_capture_tiles.py <пакет>
python3 <путь-к-скиллу>/scripts/write_checksums.py <пакет>
python3 <путь-к-скиллу>/scripts/verify_checksums.py --strict <пакет>
```

Сборку пропустить, если сохранены исходные цельные файлы или координаты кадров неизвестны. Скрипт сборки требует локальный Python-пакет Pillow; при его отсутствии не заменять локальную сборку загрузкой семейных изображений во внешний сервис. Скрипт размещает кадры по записанным координатам и не исправляет ошибочное совмещение, поэтому стыки проверить визуально. После создания новых производных файлов заново записать и проверить контрольные суммы.

Проверить непрерывность позиций, наличие ожидаемых кадров, размеры, выход координат за полотно, нулевые файлы и точные дубликаты между позициями. Дубликат считать предупреждением для ручной проверки, а не автоматически удалять.

## Завершать сеанс

1. Выборочно открыть начало, середину и конец каждого диапазона.
2. Вычислить SHA-256 доказательных и производных файлов после их создания.
3. Собирать изображения только из координат исходных кадров; не применять генеративную дорисовку.
4. Создать контактные листы и OCR после окончания ограниченного доступа.
5. В журнале указать полный охват, исключения, сбои, тип полученной копии и ссылку на пакет.
6. Не считать технически пройденную или разреженно сохранённую страницу содержательно прочитанной.
