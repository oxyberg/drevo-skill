# Отчёты

Хранить здесь доказательные отчёты по людям, семьям, населённым пунктам и завершённым этапам. Отделять цитаты и расшифровки от интерпретации; указывать статусы утверждений и альтернативные объяснения.

На один исследовательский вопрос или пакетную работу вести один обновляемый Markdown-отчёт. Не создавать отдельные файлы для каждой итерации, батча или промежуточной попытки. Новый файл оправдан только другим вопросом, другим самостоятельным документом или делом, другой персоной или ветвью либо независимо цитируемой единицей.

Для проверки доказательной непрерывности линии использовать `generation-audit.template.md`. Исходную таблицу можно собрать скриптом `assemble_generation_audit.py` из скилла «Древо»; автоматически найденные ссылки `SOUR` считать только кандидатами для ручного чтения, а не подтверждением родства. Финальный отчёт оформлять как доказательный вывод с четырьмя колонками `Переход / Что имеется / Статус / Что требуется`; служебные параметры сборки и пустые разделы удалять.
