# Архивирование веб-страниц

Создавать пакет только для страницы, которая подтверждает конкретное утверждение или происхождение документа.

## Структура пакета

```text
YYYY-MM-DD_фамилия-имя_описание_домен/
├── metadata.yml
├── excerpt.md
├── sha256.txt
├── page.warc.gz
├── page.pdf
├── page.html
└── screenshot.png
```

Включать только реально полученные форматы.

## Порядок

1. Записать исходный и конечный URL.
2. Сохранить доступный оригинальный документ отдельно в `../documents/`.
3. По возможности создать WARC/WARC.GZ и визуальную PDF-копию.
4. При техническом ограничении сохранить доступный HTML/PDF или снимок экрана и описать недостаток.
5. Заполнить `metadata.yml` по шаблону.
6. В `excerpt.md` указать значимый фрагмент, его расположение, утверждение и признаки идентификации.
7. Вычислить SHA-256 каждого файла снимка; не включать сам `sha256.txt`.
8. Добавить ссылку на пакет в журнал.

Не сохранять cookies, токены, заголовки авторизации, персональную сессию и лишние сведения потенциально живых людей. Соблюдать условия использования и авторские права.
