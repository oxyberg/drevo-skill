# Расшифровки

Хранить здесь расшифровки документов из соседнего каталога `documents`. Для одного самостоятельного документа использовать то же базовое имя файла. Для пакета последовательных сканов одного дела или вопроса вести один обновляемый Markdown-файл.

Нечитаемые места обозначать явно. Предположения заключать в квадратные скобки и объяснять. OCR маркировать как OCR и не выдавать за оригинал.

Для каждой расшифровки указывать источник изображения, позицию просмотрщика, архивный лист или оборот при уверенном чтении и точный охват. Различать технический, обзорный, кластерный и построчный проходы.

OCR хранить отдельно как навигационный индекс. Каждое совпадение проверять по изображению; отсутствие OCR-совпадения не считать доказательством отсутствия записи. Нормализованный текст хранить отдельно от буквальной расшифровки.

В пакетном файле создавать секции по локальным файлам, позициям просмотрщика или архивным листам. Не создавать отдельный `.md` для каждого скана, батча, OCR-прохода или повторного чтения. Разделять файлы только по смыслу или происхождению.

Начинать новый файл можно с [`transcription.template.md`](transcription.template.md), а для следующего кадра или прохода добавлять раздел в уже выбранный файл.
