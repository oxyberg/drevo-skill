# Документы

Хранить здесь только компактные неизменённые копии и фрагменты первичных документов, прямо относящиеся к исследуемому утверждению. Для каждого файла указывать происхождение, URL или архивный шифр и дату доступа в `research/research-log.md`.

Вычислять SHA-256 после получения. Не перезаписывать оригинал производной или обработанной копией.

Для многостраничного архивного просмотрщика создавать отдельный пакет фиксации. Разделять исходные кадры, собранные изображения, производные файлы и контрольные материалы. В метаданных связывать локальный файл с позицией просмотрщика и отдельно с видимым архивным листом или оборотом.

Если получен снимок просмотрщика, прямо называть его снимком и описывать масштаб, водяные знаки, перекрытия интерфейсом и неполный охват. Не выдавать его за исходный мастер-файл архива.

## Холодное хранилище

Полные пакеты сканов и технические производные по умолчанию хранить вне Git. После фиксации провести аудит пакета, записать и проверить SHA-256, а после переноса проверить суммы повторно. В `cold-storage-index.md` внести логический ID, относительный путь, объём, число файлов и контрольную сумму манифеста. Абсолютный корень хранилища указывать только в игнорируемом `cold-storage.local`.

В репозиторий переносить минимальный непрерывный доказательный фрагмент и необходимый для проверки контекст. Не переносить посторонние страницы, записи и их расшифровки. Полное хранение в Git допускается только по явной просьбе пользователя и после изменения политики хранения.
