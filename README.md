# Навык «Древо»

«Древо» — скилл для Codex, OpenCode и Claude Code, который помогает создавать, исследовать и вести приватное генеалогическое древо с проверяемыми источниками. Он хранит дерево в одном каноническом GEDCOM 5.5.1, отделяет подтверждённые факты от гипотез и помогает не раскрывать данные живых людей.

Исходники скилла находятся в [`drevo/`](drevo/). Codex, OpenCode и Claude Code используют один `SKILL.md`, поэтому инструкции не дублируются и не расходятся между версиями.

## Возможности

- создавать готовую структуру генеалогического проекта;
- импортировать, проверять и аккуратно изменять GEDCOM;
- исследовать предков по архивным и веб-источникам;
- фиксировать происхождение фактов, гипотезы и противоречия;
- готовить архивные запросы и отчёты о проведённом исследовании;
- проверять ссылки между персонами, формат GEDCOM и контрольные суммы доказательств.

## Установка в Codex

Попросите Codex установить скилл из GitHub:

```text
Установи скилл «Древо» из https://github.com/oxyberg/drevo-skill, путь drevo
```

Или скопируйте папку `drevo` вручную:

```sh
git clone https://github.com/oxyberg/drevo-skill.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R drevo-skill/drevo "${CODEX_HOME:-$HOME/.codex}/skills/drevo"
```

Файл `drevo/agents/openai.yaml` содержит метаданные интерфейса Codex и безопасно игнорируется другими платформами.

## Установка в OpenCode

Глобально:

```sh
./scripts/install-opencode.sh --global
```

В конкретный проект:

```sh
./scripts/install-opencode.sh --project /path/to/project
```

Проверить обнаружение:

```sh
cd /path/to/project
opencode debug skill
```

Папку `drevo` также можно скопировать вручную:

- в проект: `.opencode/skills/drevo`;
- глобально: `~/.config/opencode/skills/drevo`.

После обнаружения OpenCode показывает скилл `drevo` агенту и загружает его по запросу. Агент может выбрать скилл автоматически по `description`; для явного вызова попросите OpenCode использовать скилл `drevo`.

## Установка в Claude Code

Глобально:

```sh
./scripts/install-claude.sh --global
```

В конкретный проект:

```sh
./scripts/install-claude.sh --project /path/to/project
```

Проверить установку можно командами `/skills` и `/drevo` внутри Claude Code. Для ручной установки скопируйте папку `drevo` в `.claude/skills/drevo` в проекте или `~/.claude/skills/drevo` для глобальной установки.

## Использование

Явный вызов зависит от платформы:

- Codex: `$drevo`;
- OpenCode: «Используй скилл `drevo`»;
- Claude Code: `/drevo`.

Например, в Codex:

```text
$drevo
```

Скилл также может выбираться автоматически. Фразы «Древо», «генеалогическое древо», «семейное древо» и «родословная» указаны как явные триггеры. Технический идентификатор остаётся `drevo`, поскольку имена скиллов используют латиницу.

Примеры:

```text
Используй Древо, чтобы создать новый генеалогический проект.

Используй $drevo, чтобы проверить family-tree.ged и найти ошибки в родственных связях.

Древо, помоги исследовать предка и сохранить источники.
```

## Приватность

«Древо» по умолчанию не публикует генеалогические данные, не загружает документы во внешние сервисы без разрешения и ограничивает поиск данных о потенциально живых людях.
